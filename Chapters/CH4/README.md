# Chapter 4: lucid polished edition

This is an independent aa-flow-lucid polish of CH4_REWRITE. The original and
the earlier rewrite remain untouched.

The revision preserves the rewrite's mathematical structure, equation labels,
theorems, and substantive additions while restoring some of the original
chapter's warmth, explanatory cadence, and time-course visual language.

Build the standalone chapter from this directory with:

    latexmk -pdf main.tex

The standalone wrapper sets the chapter counter to 4. The restored two-panel
load/release figure is generated by figures/_work/N3.6/generate.py. Four figures
from the original chapter are retained for provenance in
figures/original_archive/; they are not all inserted into the compiled chapter.
