# Figure: first-event map (paper caption)

First-event decomposition of the backward equations.
In a short interval $\Delta t$ a single individual undergoes at most one event; conditioning on which event occurs first partitions the finite-time no-catastrophe probability.
Upper panel: one type-1 individual.
With probability $1-(\lambda_1+\mu_1+\nu+\delta_1)\Delta t$ nothing happens and the residual contribution is $S(t)$; a birth contributes $S(t)^2$; an ordinary death contributes $1$; conversion contributes $G(t)$; catastrophe contributes $0$.
Lower panel: the type-2 analogue (no conversion), with residual contributions built from $G(t)$.
Collecting rates recovers the triangular system of \cref{eq:backward-unscaled}.
Symbolic schematic only.
